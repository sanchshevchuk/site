# Single-Page Commercial Landing

Minimalist, high-performance landing page for web development services.

🔗 **Live:** [site.shevchuk.vn.ua](https://site.shevchuk.vn.ua)

## Tech Stack
* **Frontend:** HTML5, Modern CSS3 (`flexbox`, CSS custom properties, `100dvh`), Vanilla JavaScript
* **Dependencies:** None

## Infrastructure & Setup
* **Hosting & CI/CD:** GitHub Pages
* **DNS & Security:** Cloudflare DNS, SSL/TLS (Let's Encrypt, forced HTTPS)
* **Email Routing:** Cloudflare MX / SPF routing for custom domain inbox
* **SEO & Meta:** Schema.org JSON-LD structured data, OpenGraph, dynamic SVG favicon, `sitemap.xml`, `robots.txt`
